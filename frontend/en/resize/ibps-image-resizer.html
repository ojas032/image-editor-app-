Official IBPS Image Specifications

When applying for IBPS exams (PO, Clerk, SO, RRB), you must adhere to strict image dimension and file size requirements. Failure to do so may result in your application being rejected.

Photograph

  • Dimensions: 200 x 230 pixels
  • File Size: 20KB to 50KB

Signature

  • Dimensions: 140 x 60 pixels
  • File Size: 10KB to 20KB
